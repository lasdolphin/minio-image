# Upstream source and licensing

This project builds public OCI images from an exact release and commit of
[`minio/minio`](https://github.com/minio/minio). The build workflow records both
values in image labels and its public run summary.

MinIO Community is licensed under AGPLv3-or-later. Corresponding source is
available from the upstream release tag and commit recorded on each image. This
repository contains no MinIO source changes.
